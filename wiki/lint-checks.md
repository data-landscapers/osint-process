# lint-checks.md — why the lint checks are shaped as they are

*(The reasoning and the finer detail behind `LINT.md`, which keeps each check to its command, cadence and rule. By check number; checks with nothing to explain are absent.)*

**Cadence.** The test is whether the work scales with the night's catch. A check that reads and judges runs over the night's new records only, because judging the whole vault nightly costs the same every night for nothing new. Whole-vault work that costs the same at any cadence is batched to full lint.

**#3 Freshness.** A figure inherits its bullet's date, except in a one-line index bullet.

**#6 Inadmissible sources.** A `NOVEL` origin showing one of the five hostile shapes goes to `origin-screen.md` → *After a promotion to `drop`*. The scripted half also flags an `origin_status: cleared` stamp that predates its own domain's adjudication: that stamp is residue from the session that promoted the domain, and housekeeping 104 found four records that had survived three promotions. The host is matched in full, never as the registrable domain, so one tenant of a shared host does not condemn another.

**#7 Duplicates.** Retire only where the loser's unique figures and parties are empty or chrome. Where neither record is better, keep the first by filename.

**#8 Page bloat.** Until 2026-09-20 the check did not exist, and every count was measured ad hoc: 199, 295, 342, 394 pages over three weeks, each disagreeing with the last. The hub exemption was specified and applied nowhere, so `places/NGA.md` counted 56,296 words when 51,665 were its compiled chronology. The script reports three counts — `concepts/`, `places/`, `intersections/` — because they have three remedies. Links, sources and a `Length` note are furniture and exempt; a dated *Record not held* is content, since an absence stated with a date is a finding. Findings are soft: §8's word figures are prompts, and a page over the line may correctly be left alone, which is what a current `## Length — reviewed` ruling records. Since R66 the gate sits at Phase B's write, and #8 only counts.

**#14 `url:` quality.** The search order: the record's own `source:`-type key, then title, document ID or DOI, a publisher search, an archive, a byte-compare of a held artefact. A 200 is not proof: verify title and date. A homepage capture with no dated event is not a defect.

**#21 Machine-record audit.** Class 2 (empty `entities: []`) never gates. The truncation tests are heuristics, and a known false positive left in the count keeps the gate red on the same record every night, so a hit that reading shows complete is recorded once as cleared and the flag stays `full`.

**#24 Register caps.** A check that fails on work the run may not edit is one that gets skipped, so the share's findings are hard only on OSINT's own files. README dropping a rule the check watches is itself hard: a check that can disarm itself is not a check. Whether an `Affects:` line is *true* is the writer's; a check that adjudicated it would pass everything or argue with its writer. CORPUS asserts the same from `scripts/lint-preambles.py` and `scripts/lint-notes.py`.

**#25 `CLAUDE.md` length.** A standing rule read past the date it names is read as live and is not; hence the freeze-date finding.

**#34 Catalogue hero.** Nothing is surfaced because the record sits in the public catalogue either way: there is no refusal to record and no judgment for Bill. Pre-contract sources carry none by construction and are a backfill process's work.

**#35 Hard-wrapped paragraphs.** It refuses `raw/`, which is immutable and verbatim, and the append-only `logs/` ledgers, where one line is one record, never a paragraph. The fix is mechanical and needs no reading.

**#36 Entity slugs.** Filed as #30 on 2026-08-23 against a handle already taken, and renumbered 2026-09-08: a handle is never reused.

**#38 De-accented titles.** The accent test alone over-reports by about a quarter, so a flattened spelling (`-cao`, `n.o`, `Politica`, `donnees`) is required with it. A reconstructed title on a gazette citation is a fabricated one, which is why only a refetch fixes it.

**#39 Artefact md5 collisions.** A document served from two routes defeats both dedup gates: ingest's tier 3 reads titles and ledes, and the URL index reads URLs. Both companion pages then read as legitimate records to every other check (job 106, found by accident nine days late). The check never rebuilds the index, because hashing every artefact takes minutes, but it reports a row count that has fallen behind the trees. Three of the four collision shapes are legitimate: one document evidencing two records, a budget document held in both `budget-archive/` and `raw/`, a table reprinted in the next year's document. A ruled row stops a real collision hiding among nine known ones reported every night.

**#40 A record no parser can read.** A fence carrying a doubled CR, or one that has lost its newline, reads as *no* frontmatter rather than bad frontmatter, so every text-mode check passes over the record silently. Three Somali records sat unread until `catalogue-hero-set.py` refused one (housekeeping 118). A doubled CR inside the body is the soft half of the same capture fault.

**#41 Documentation caps.** Cutting a process file is a rewrite: the rule stays as one sentence and its argument moves to the spec that owns it, one file a sitting (strategic review 5 R90, R93). A trim made by lint would drop rules along with prose.
